02 · Governed memory

Memory you can audit, not a black box.

The enterprise wedge isn't recall — it's governed recall. Every fact is scoped, sourced, and revocable.

SCOPED

Scoped to the customer

Every memory is bound to one account. Nothing bleeds across tenants, ever.

SOURCED

Provenance-backed

Each fact carries where it came from and when. Every recall is traceable to a session.

REVOCABLE

Forgettable by design

Facts expire and can be revoked on request. Memory you govern — not a store that hoards.

CURRENT

Not long-context

Durable distilled facts, not a transcript stuffed into the prompt. Cheaper, current, explainable.

03 · How it works

From conversation to durable fact.

01WRITE

Capture

Every session is recorded as episodic memory — the raw record of what happened.

02DISTILL

Distill

Episodes are compressed into durable, scoped facts with their source attached.

03RECALL

Recall

On a new session, only the facts scoped to that customer are surfaced to the agent.

04SCORE

Measure

An evaluation harness scores repeat-question rate. With memory 0.00, without 1.00.

PROOF

We measured it. In a controlled ablation — the same agent with memory toggled off — repeat-question rate moves from 0.00 to 1.00. Every returning customer forced to re-explain. Memory is the difference between zero and one.
